# Junkbox

Junkbox is a simple jukebox in a cyberpunk style.

I was lazy so *it as been created with AI*

The texts are in french, feel free to modify to whaterever language you whant (be carefull that the font can handle your alphabet)

## Fonctions : 

* Play music
* Queue multiples musics
* Need credit
* Differents folders to classify musics
* Handle keyboard and gamepad input
* Progress bar
* Glitchs and scanline animations
* Customizable font

## Input

* UP / DOWN : choose track
* LEFT / Right : choose folder
* SPACE / SELECT : credit
* ENTER / A button : play / queue
* S / B button : stop
* ESCAPE / Q : quit

## Add music

Just put the audio files (wav,mp3,ogg,flac) in a subfolder inside music folder

```
- music
    - pop
        - rickroll.wav
        - nyancat.mp3
    - rock
        - granit.flac
        - diamond.ogg
```

## Customer font

If you whant to change the font just put your ttf file inside assets/fonts
